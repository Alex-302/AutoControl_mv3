Force enable "Manifest V2" support

Note: This method does not work in Chromium-based browsers newer than version 150, where the "Manifest V2" support policy was removed entirely.
Starting on October 2024, Google Chrome will gradually disable support for "Manifest V2" extensions.
This will affect AutoControl and spin-off extensions such as Tab Switcher and Per Tab Zoom.
Alternative: you can also keep "Manifest V2" support enabled without touching the registry, by launching your browser with the following command-line parameter (e.g. via a desktop shortcut or a script):
"C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-features=ExtensionManifestV2Unsupported,ExtensionManifestV2Disabled
Note that the parameter must be present every time the browser is started, otherwise "Manifest V2" extensions will be disabled again.
You can continue using these extensions by forcing Chromium browsers to keep "Manifest V2" support enabled until at least June 2025. This is achieved by adding a special setting to the Windows registry. Please follow these steps:
  1. Download this file to your computer.
  2. Double-click on the file and confirm the message box.
  3. Go to chrome://policy and click on the "Reload policies" button.
Once you add this setting, your browser will show the message "Your browser is managed by your organization" on various settings pages such as chrome://settings and chrome://extensions. This message is shown whenever the browser detects a registry setting. That's all it means.
You can remove the registry setting by following these steps:
  1. Download this file to your computer.
  2. Double-click on the file and confirm the message box.
  3. Go to chrome://policy and click on the "Reload policies" button.
The registry file works for most Chromium browsers such as Chrome, Edge, Brave, Vivaldi and others. If it doesn't work on your particular browser, please ask for help at the Support Forum by mentioning your exact browser brand and version.
